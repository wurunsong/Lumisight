Lumisight：Agent 主流程与技术亮点（详细链路版）

强调“流程完整性 + 差异化技术链路”。外挂知识库（向量/图谱）作为可插拔增强链路保留，不和在线主编排耦死。

1. 端到端主流程（离线构建 + 在线执行）

代码仓离线解析
→
向量/图谱构建
→
在线请求接入
→
Agent 决策编排
→
工具执行回填
→
事件流/最终答案

2. Agent 详细执行链路（完整分段）

2.1 入口归一化链路

  • 触发：SSE 请求或 WS 命令进入系统。
  • 处理：统一映射为 AgentRequest，补齐会话与运行参数。
  • 保护：请求校验在入口完成，非法参数提前失败。
  • 输出：形成可执行的标准化请求对象。

2.2 会话调度链路

  • 触发：同一 session 在运行中收到新问题或控制命令。
  • 处理：FOLLOW 排队、COLLECT 合并、STEER 抢占并推进 epoch。
  • 保护：single-flight + 状态机迁移校验，避免并发状态漂移。
  • 输出：得到确定性的会话执行顺序。

2.3 技能与策略链路

  • 触发：请求进入决策前的策略准备阶段。
  • 处理：显式 skill 或自动路由 skill，生成本轮策略与权限边界。
  • 保护：低置信 skill 回退默认路径，避免误路由放大错误。
  • 输出：得到受约束的编排上下文与可用工具集合。

2.4 决策循环链路

  • 触发：编排引擎启动轮次循环。
  • 处理：模型在每轮输出 tool / ask_user / final 决策。
  • 保护：轮次上限、决策解析容错、防止无限循环。
  • 输出：把复杂问题拆成可执行的多轮动作。

2.5 工具执行链路

  • 触发：决策选择具体工具及参数。
  • 处理：权限校验 -> Hook 检查 -> 工具调用 -> 结果标准化。
  • 保护：重试/回退、超时治理、错误结构化返回。
  • 输出：工具证据回填上下文，驱动下一轮决策。

2.6 人工门控链路

  • 触发：检测到高风险写操作。
  • 处理：挂起为 HUMAN_GATE，等待用户 approve + resume。
  • 保护：未确认不执行，确认后仅恢复挂起决策。
  • 输出：实现“可控写入”的人工闭环。

2.7 最终答案链路

  • 触发：决策收敛到 final 或达到可回答状态。
  • 处理：必要时进行答案复核，再生成最终输出流。
  • 保护：复核失败回退继续推理，防止低质量直接出结果。
  • 输出：返回 FINAL/TOKEN 事件与可追踪证据。

2.8 清理与恢复链路

  • 触发：完成、异常、中断或长时间等待。
  • 处理：释放会话租约、更新状态、定时清理过期等待态。
  • 保护：防止会话泄漏与僵尸状态堆积。
  • 输出：系统回到可持续服务的稳定基线。

3. 外挂知识库链路（你这套的核心增强点）

3.1 离线知识沉淀链路

  • 触发：仓库变更后启动离线构建（全量或增量）。
  • 处理：代码解析后分别沉淀到向量层与图谱层。
  • 保护：构建失败不阻塞在线 Agent 主链路启动。
  • 输出：形成可被在线查询的结构化代码知识资产。

3.2 在线知识注入链路

  • 触发：问题需要证据时，决策层选择 RAG/KG 相关工具。
  • 处理：召回结果以统一上下文项回填到推理上下文。
  • 保护：无外挂依赖时自动降级为 Noop provider。
  • 输出：有知识库时增强准确性，无知识库时仍可回答。

3.3 知识与主编排解耦链路

  • 触发：部署环境不同（开发机/测试机/生产）。
  • 处理：通过开关决定是否启用外挂知识库能力。
  • 保护：知识库不可用不会导致核心执行引擎失效。
  • 输出：实现“可增强但不依赖”的弹性架构。

4. 技术亮点链路（详细版）

亮点 A：协议解耦

  • 请求进入协议适配层。
  • 统一映射到同一执行引擎。
  • 执行结果回到事件通道抽象。
  • 协议层仅负责分发与序列化。
  • 新增协议时只扩适配层。

亮点 B：会话控制

  • 运行中收到新问题触发会话调度。
  • FOLLOW/COLLECT/STEER 路径分流。
  • 状态机约束迁移合法性。
  • 等待态超时自动清理。
  • 保证会话行为可预测。

亮点 C：安全执行

  • 决策触发工具调用。
  • 权限与策略先行校验。
  • Hook 可阻断危险调用。
  • 写入前快照、失败可回滚。
  • 形成可控执行闭环。

亮点 D：Skill 路由

  • 问题进入技能路由器。
  • 输出候选 skill 与置信度。
  • 低置信回退默认路径。
  • 执行计划影响权限与策略。
  • 兼顾自动化与可控性。
说明：这里刻意不罗列 `xxx.yyy.zzz` 配置项；重点是讲清楚“链路如何运转、在哪保护、产出什么价值”。
