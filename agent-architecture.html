Lumisight：统一架构蓝图

这份图是“当前有效架构”的单一视图：融合历史演进结果，不按日期堆叠。离线知识库与在线 Agent 可解耦运行，生产和本地调试都能复用同一主链路。

1. 端到端主流程
离线解析仓库
→
构建向量/图谱
→
启动 Agent Runtime
→
Loop 编排 + 工具执行
→
SSE 事件流输出
→
最终答案与证据
2. 在线分层架构（先整体）

A. API 接入层

  • 统一前缀：`/api/lumisight`
  • Agent：`POST /agent/stream`（SSE）
  • KG/Vector 接口按开关条件暴露
  • 异常统一映射：401/404/500

B. Agent 编排层

  • 核心：`CodeAssistantAgentService`
  • 模式：`NORMAL` / `PLAN`
  • 动作：`tool` / `ask_user` / `final`
  • 技能：默认技能 + `skillPath` 文件技能

C. Tool 执行层

  • 按权限与类别统一注册调度
  • 本地/Git/LSP/构建/向量/图谱工具协同
  • 工具别名与参数兼容映射
  • 高风险调用可被 Hook 前置拦截

D. 事件与会话层

  • 事件：`PLAN/TOOL_CALL/TOOL_RESULT/TOKEN/FINAL`
  • 反问与人工门控：`ASK_USER/HUMAN_GATE`
  • 可观测状态：`LOOP_STATE/VERIFY_RESULT`
  • 支持会话中断与续跑
3. Agent 决策与执行闭环（再分点）

3.1 决策循环

  • 请求校验后进入最大轮次控制的 loop
  • 每轮模型给出结构化决策 JSON
  • 工具结果回填上下文驱动下一轮
  • 信息不足走 `ask_user`，避免错误收敛

3.2 质量与门控

  • 答案复核改为条件触发，降低对话时延
  • 高风险写操作支持人工确认
  • 失败策略支持 retry/fallback
  • 权限不足/未知工具返回结构化错误事件

3.3 Hook 与技能扩展

  • Hook：读取 `.codeflicker/config.json` 的 `PreToolUse`
  • 命令钩子可按规则阻断危险调用
  • 技能支持外部文件注入，不污染主流程
  • 默认对话链路与技能链路可独立演进
4. Sandbox 安全执行与回滚
统一命令执行入口
→
超时/输出上限/网络开关
→
local 或 docker 隔离执行
→
写前快照
→
rollbackRepoFile 回滚

4.1 执行策略

  • 统一 `SandboxCommandRunner` 承接命令执行
  • 全局网络策略：`lumisight.sandbox.network-enabled`
  • Docker 模式支持 CPU/内存/PID 限制
  • Git 工具已统一接入 sandbox 执行器

4.2 可回退写入

  • `writeRepoFile` 自动生成 `snapshotId`
  • 快照目录由 `snapshot-dir` 管理
  • `rollbackRepoFile` 按快照恢复文件
  • 形成“可执行 + 可撤销”闭环

4.3 运行模式建议

  • 本地调试优先 `local` + 网络关闭
  • 高隔离场景切 `docker` 模式
  • 无 KG/Vector 环境可仅跑 Agent
  • 生产环境按权限最小化原则配置
5. 离线知识库子系统（可选增强）

5.1 Milvus 向量层

  • 双集合：`code_chunk` / `symbol_doc`
  • 支持全量与增量入库
  • 向量元数据关联源码与符号
  • 关闭开关时不影响 Agent 启动

5.2 Nebula 图谱层

  • 节点：module/package/class/method
  • 边：contains/calls 等语义关系
  • 构建服务支持按仓库增量更新
  • 按 `lumisight.kg.enabled` 条件装配

5.3 与 Runtime 协同

  • RAG/KG 作为可插拔上下文提供者
  • 无外部依赖时自动降级 Noop Provider
  • 避免 Bean 缺失导致应用启动失败
  • 保证主链路始终可调试
6. 关键配置与开关

功能开关

  • `lumisight.kg.enabled`
  • `lumisight.vector.enabled`
  • `taskType` 支持 `CHAT` 且可为空
  • `skillPath` 可选注入技能文件

Sandbox 开关

  • `lumisight.sandbox.enabled`
  • `lumisight.sandbox.mode`
  • `lumisight.sandbox.timeout-seconds`
  • `lumisight.sandbox.max-output-bytes`

调试入口

  • 浏览器控制台：`/agent-console.html`
  • SSE 事件流实时回放
  • 可替代 Postman 做交互调试
  • 兼容纯本地 Agent 模式
